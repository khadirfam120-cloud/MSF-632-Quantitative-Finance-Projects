# MSF 632 Quantitative Finance Project Series

A four-part Python project analyzing investment returns, portfolio risk, diversification, and simulation methods.

## Project parts
1. **IVV returns and compounding:** Monthly return statistics and investment growth from 2016–2025.
2. **Historical returns and diversification:** Daily S&P 500, IBM, and Coca-Cola returns, distribution statistics, and an equal-weight portfolio.
3. **Distributions and simulation:** Central Limit Theorem demonstrations and Monte Carlo simulations.
4. **IVV–AGG portfolio analysis:** Rebalanced and buy-and-hold 60/40 portfolios, simulated loss scenarios, and regression analysis.

## Tools
Python, pandas, NumPy, SciPy, statsmodels, matplotlib, yfinance

## Note
This is an academic project. Historical results and simulations are for educational analysis and do not predict future performance.
